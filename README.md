# 带键盘事件的计算器（Qt 实验一）

东莞理工学院计算机科学与技术学院 · Qt 应用程序开发 · 实验一

## 一、实验目标

设计一个支持四则运算的计算器，要求：

- 使用 Qt Designer 完成界面布局与控件属性设置；
- 支持加减乘除、小数输入、退格、清除；
- 正确处理连续小数点、连续操作符等异常输入；
- 支持键盘输入，且与鼠标输入复用同一套处理逻辑；
- 正确处理除零、结果后继续输入、连续运算等边界情况；
- 使用 Git 管理代码，体现迭代、测试与问题修复过程。

## 四、构建与运行

直接双击运行 `build.bat`，或在命令行执行：

```
build.bat
```

产物位于 `build/release/QtCalculator.exe`。

> **本机环境说明**：本机 qmake 在探测编译器时会报 `QProcess: CreateFile failed`，
> 导致无法自动获取编译器信息。`build.bat` 会自动调用
> `tools/gen_qmake_stash.py` 预先探测编译器并写入 `.qmake.stash` 缓存，
> 从而绕开该问题，保证构建可复现。

## 五、功能设计要点

### 1. 运算状态管理

计算器用四个成员变量集中管理运算状态，避免了散落的局部变量：

| 变量 | 含义 |
|---|---|
| `m_operand` | 第一个操作数（左操作数） |
| `m_pendingOp` | 待执行的运算符（空串表示无） |
| `m_isEnteringNumber` | 是否正在输入新的操作数 |
| `m_hasResult` | 显示区当前是否为运算结果 |

### 2. 鼠标与键盘复用同一套逻辑

`keyPressEvent()` 只负责把按键**翻译**成语义动作，具体处理全部调用与鼠标点击
相同的槽函数，因此两种输入方式行为完全一致：

```
键盘 '+'  ─┐
鼠标 '+'  ─┴─→ applyOperator("+")  →  同一套状态机
```

### 3. 异常输入处理

| 异常输入 | 处理策略 |
|---|---|
| 连续小数点 `3...14` | 一个操作数内只保留第一个小数点 |
| 连续操作符 `5 + ×` | 替换为最后按下的运算符 |
| 除数为 0 | 提示「除数不能为 0」，显示区变红 |
| 结果后继续输入数字 | 自动开始新的操作数 |
| 输入前导 0 `05` | 用新数字替换掉初始的 0 |
| 超长输入 | 限制为 17 位，忽略后续输入 |

### 4. 界面美化

通过 Qt 样式表（QSS）统一美化，并借助**动态属性** `btnRole` 给不同类别的按键
分配配色，避免为每个按钮单独写样式：

- 数字键：白底深色字
- 功能键（C / ± / % / ←）：浅灰底
- 运算符键（÷ × − +）：浅蓝底 + 蓝色文字
- 等号键：蓝色实心 + 白色文字

## 六、自动化测试与截图

`tools/screenshot_tool.cpp` 是一个自动化测试工具，用消息投递模拟真实的鼠标点击与
键盘敲击，覆盖 16 个关键场景，并逐张保存界面截图：

```
QtCalculatorShots.exe -platform offscreen
```

覆盖场景：初始界面、鼠标小数运算、重复小数点、键盘输入、键盘求值、退格、
除零、连续运算、连续操作符、结果后继续输入、清除与重算。
